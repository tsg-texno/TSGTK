# TSG Toolkit 0.3 — автоматические действия

## Запуск с доступом к компьютеру

```powershell
npm ci
npm run build
npm run local
```

После сборки можно запускать `start-toolkit.cmd` двойным щелчком. Окно должно оставаться открытым. Адрес тот же: http://127.0.0.1:4173/. Если порт занят прежним preview, остановите его. Порт и профиль браузера желательно сохранять: там находятся IndexedDB-проекты.

В отличие от `npm run preview`, `npm run local` включает небольшой локальный сервер с доступом к системным папкам и состоянию процессов. Он работает с правами запустившего его пользователя, без внедрения в игру, изменения игровых файлов и запуска самой Arma/TeamSpeak. При отсутствии прав доступа показывается ошибка; приложение не пытается обходить запрет. Для удалённого размещения этот локальный интерфейс не предназначен.

## Log Doctor

- При открытии модуля автоматически ищется последний RPT в `%LOCALAPPDATA%\Arma 3` и выполняется анализ. Второй по времени журнал используется для сравнения.
- Есть список найденных RPT и кнопка повторного анализа. Порядок файлов определяется временем изменения, не алфавитным именем.
- Можно включить автопроверку каждые 15 секунд. При скрытой вкладке опрос не выполняется; после закрытия модуля прекращается. Если файл не изменился, повторный разбор не запускается.
- Когда обнаружен процесс Arma 3, автоматическое чтение RPT приостанавливается до выхода из игры. Это не сбор телеметрии активного матча.
- Для `-profiles` или нестандартного расположения есть поле «Каталог RPT». Пути записываются в `.local/settings.json`, исключённый из Git.
- Ошибки объединяются по сообщениям и категориям, доступны фильтры, число повторов, номера строк и рекомендации. Сохранённый отчёт маскирует известные приватные поля. Исходные RPT не публикуются, не изменяются и не копируются в репозиторий.
- Максимум 20 МБ на файл, 300 000 строк и 500 групп. Ручная загрузка RPT в обычной PWA сохранена.

Стандартный путь и влияние `-profiles` / `-noLogs` проверены по [Bohemia: Debugging Techniques](https://community.bistudio.com/wiki/Debugging_Techniques) и [Crash Files](https://community.bistudio.com/wiki/Crash_Files?useskin=darkvector). Если журналов нет, приложение не придумывает результат диагностики.

## Preflight

Автопроверка выполняется при открытии модуля и повторяется кнопкой «Проверить компьютер». Результат сохраняется с датой как снимок, отдельно от пользовательского чек-листа.

Проверяется наличие executable Arma в реестре/библиотеках Steam, стандартные установки TeamSpeak, наличие соответствующих процессов, DLL TFAR в папках plugins, PBO в addons указанных каталогов модов и доступность RPT. Дополнительные библиотеки Steam читаются из libraryfolders.vdf. Нестандартные пути задаются в интерфейсе. Список требуемых модов TSG не выдумывается.

Наличие файла не доказывает актуальность мода, включённость TFAR или готовность радиосвязи. Эти результаты так и подписаны. Отсутствие доступа к RPT не отменяет остальные проверки. Контрольные суммы, параметры сервера TeamSpeak и реальное соединение TFAR пока не проверяются.

«Проверить звук» воспроизводит короткий сигнал. «Проверить микрофон» по разрешению пользователя показывает уровень входного сигнала в течение 10 секунд; можно остановить раньше. Поток закрывается при уходе со страницы. Запись не сохраняется и никуда не передаётся. Автотесты не запрашивали настоящий микрофон пользователя.

## Academy

Шесть тем: шестизначные квадраты и постановка метки, азимут, дистанция, доклад о контакте, каналы карты и органы управления раций TFAR. Выбирается реальная локальная подложка острова; выбранное изображение сохраняется в IndexedDB для офлайн-повторения. Без библиотеки доступна учебная сетка. Тема «Рации TFAR» работает без подложки, описание и источники — в TFAR-TRAINER.md.

Видимый участок — 2 × 2 км, сетка 100 м и шкала 500 м. Шестизначный квадрат — три цифры восточной координаты, затем три северной; он обозначает ячейку, а не позицию до метра. В упражнении «Поставить метку» проверяется попадание щелчка в правильную ячейку, после ответа она выделяется. Для азимута есть переключаемый круговой компас. Дальность оценивается по карте без выдачи координат цели цифрами.

Доклад теперь нужно составить: позывной, азимут, дальность, ориентир. Числа проверяются относительно позиций A/B; текст ориентира проверяется только на заполненность. Речь и тактическая уместность автоматически не оцениваются. Сценарии каналов основаны на формулировках руководства и помечены как учебные, с прямой ссылкой на источник.

Источники: [TSGuide — Радиообмен](https://guide.tsgames.ru/comms), [TSGuide — Карта](https://guide.tsgames.ru/map). Упражнения авторские, не официальный экзамен проекта. Новые задания не загружают текущую миссию или сведения об игроках.

Импортёр карт формирует trainingSpots по исходной сетке R16: точки на суше, отступив от краёв. После обновления можно повторить `npm run maps:import -- "путь к Maps"` и сборку. Подложки всё ещё содержат рельеф, без дорог, зданий и подписей.

## Ограничения локального API

Сервис слушает только 127.0.0.1. Проверяет Host, Origin, Fetch-Site и специальный заголовок; CORS не включён. Нет API произвольного чтения файлов или выполнения команд. RPT ограничены одним выбранным каталогом, расширением, размером и проверкой реального пути. Настройки принимают только абсолютные локальные пути. Системная команда фиксирована, пользовательский текст в неё не подставляется. Все файлы приложения отдаются только из dist. Сервис нужен только пока используется автодоступ.

Проверки: `npm test`, `npm run test:local`, `npm run test:browser` (при работающем сервере). Тесты используют отдельные каталоги и браузерные профили. В текущей сессии Codex чтение реального каталога AppData было запрещено системой; работа автопоиска и анализа проверена на изолированных RPT, а отказ в доступе отображается явно.
