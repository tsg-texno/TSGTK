# TSG Toolkit 0.2 — локальная версия

Восемь работающих модулей в общей оболочке. Новые модули используют IndexedDB `tsg-toolkit-v1`; проекты планировщика по-прежнему находятся в восьми отдельных базах сервер/сторона. Название папки проекта и npm-пакета оставлены прежними ради совместимости. Обновление приложения не переносит и не удаляет старые базы. При переходе из планировщика в другой модуль редактор остаётся смонтированным, чтобы не оборвать отложенное сохранение.

Маршруты: `#home`, `#planner`, `#preflight`, `#logs`, `#academy`, `#missions`, `#validator`, `#replay`, `#journal`. После установки PWA код всех модулей входит в офлайн-кэш. Внешние страницы TSGuide и Replay требуют сети. Никаких фоновых запросов к TSG API, облачным моделям или работающей игре нет. Ссылки пользовательских импортов ограничены HTTPS; импорт не исполняет скрипты.

## Состав и границы реализации

- **Preflight:** сохраняемый ручной чек-лист с тремя состояниями, своими пунктами, заметками и датой отметки. Автоматическое обнаружение установленной игры, процессов, активного TFAR и целостности модов требует отдельного настольного адаптера. Никакие «успешные проверки компьютера» браузер не имитирует.
- **Log Doctor:** файлы до 20 МБ / 300 000 строк, UTF-8 с резервным декодированием Windows-1251, семь групп эвристических правил. Повторы объединяются без временного префикса, до 500 групп; сравниваются новые, исчезнувшие и участившиеся группы. Сохраняется только отчёт, не исходный RPT. Пути профиля, IPv4 и Steam ID маскируются, однако это не универсальный детектор персональных данных. Выгрузка отчёта — JSON/Markdown. Не является анализом crash dump или гарантированным определением причины сбоя.
- **Academy:** процедурная сетка 10 × 10 км, проверка координат X/Y, северного азимута, дистанции и полноты учебного радиодоклада. Прогресс — последние 2000 попыток. Нет оценки навыков реального игрока, голосового распознавания, курса ACE-медицины или официального экзамена TSG. Дополняет [TSGuide](https://guide.tsgames.ru/), материалы которого не копируются в приложение.
- **Mission Explorer:** карточки с островом, автором, числом слотов, типом, версией и заметками; поиск, фильтры, редактирование/удаление, импорт/экспорт. Список не означает одобрения миссий TSG и не меняет белый список островов. Автоматический разбор PBO и доступ к закрытым архивам не реализованы.
- **Mission Validator:** структурный сканер распакованных SQM/SQF/EXT/HPP/CPP, до 100 файлов по 5 МБ. Скобки внутри строк и комментариев игнорируются. Список addOns[] / requiredAddons[] сравнивается с введённым списком addon-классов, если он задан. Проверяются незакрытые строки/комментарии и абсолютные пути Windows. Отчёт экспортируется; исходники не сохраняются. Это не полный парсер языка, не проверка движком Arma и не валидатор внутренних правил TSG. Бинарные SQM и PBO отклоняются.
- **Replay Insights:** один активный журнал завершённой игры, создание/удаление событий, фильтры по типу/подразделению, временной срез, JSON-обмен и Markdown AAR. Подсчитываются события, а не подтверждённые игровые потери. Не подключён к формату [TSG Replay Viewer](https://replay.tsgames.ru/); нужен реальный разрешённый образец данных для отдельного адаптера. Значение completed подтверждает автор импортированного журнала, а не сервер TSG.
- **Personal Journal:** до 2000 записей, дата/роль/отряд, заметки, выводы и HTTPS-ссылка на реплей. Поиск, изменение, удаление, импорт копий с новыми ID, экспорт всего журнала и отдельной записи в Markdown. Нет автоподтягивания статистики и хранения скриншотов.
- **Operations Planner:** прежний редактор и 22 локально подготовленные подложки сохранены. Точные названия линий/зон восстановлены из предыдущего чата. Старые объекты без `symbolSet` сохраняют прежнее оформление; новые получают `symbolSet: "tsg"`. Слои предложений, настоящие роли, совместная работа и серверная фильтрация — ещё будущий этап, описанный в ARCHITECTURE.md. Atlas остаётся отключён до выполнения условий.

## Форматы обмена

Реальные схемы Zod: `src/toolkit/data.ts`. Данные файлов валидируются до записи. Импорт каталога и журнала добавляет копии, не заменяя существующие записи. Экспорт сделан локальным скачиванием файла, а не отправкой в сервис.

**Каталог миссий:** массив объектов `id` (UUID), `title`, `island`, `author`, `slots` (0–1000), `kind` (`attack`, `defense`, `meeting`, `other`), `version`, `notes`.

**Личный журнал:** массив `id` (UUID), `date` (YYYY-MM-DD), `title`, `role`, `squad`, `notes`, `lesson`, `replayUrl` (пустая строка или HTTPS URL).

**События для Replay Insights:**

```json
{
  "format": "tsg-toolkit-events",
  "version": 1,
  "title": "Название завершённой игры",
  "completed": true,
  "sourceUrl": "",
  "duration": 3600,
  "events": [
    {
      "id": "b3b2f77d-d541-4ddb-b220-37bcaa341d8c",
      "time": 120,
      "kind": "note",
      "unit": "Альфа",
      "details": "Сбор завершён"
    }
  ]
}
```

`time` и `duration` — секунды, максимум 86400; события за концом записи и повторяющиеся ID отклоняются. `kind`: `contact`, `loss`, `objective`, `note`. Необязательные `x`/`y` передаются вместе в метрах. Пустой шаблон можно скачать непосредственно в модуле. Это **собственный контракт Toolkit**, не описание неизвестного API TSG.

## Следующая интеграция

`TSGApiRoleProvider`, серверные права, FastAPI/PostgreSQL/WebSocket, парсер настоящего replay-формата, PBO-парсер и настольный системный адаптер подключаются отдельно. До этого приложение предназначено для автономной подготовки/тренировки/разбора. Глобальное локальное хранилище личного журнала не должно использоваться для совместного хранения секретных штабных данных разных пользователей: оно не имеет серверной авторизации.

Доступ к исходному чату позволил восстановить набор инструментов, но предложения прежнего ассистента не трактуются как реальные форматы API или официальное одобрение TSG. Никакие секреты, локальные карты и пользовательские данные не добавляются в GitHub.
