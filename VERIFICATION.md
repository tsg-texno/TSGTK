# Проверки · 3 ноября 2026

- `npm run build`: TypeScript + production Vite + service worker/manifest, успешно.
- `npm test`: 5 проверок, успешно. Используется fake-indexeddb; проверены все восемь контекстов, чужая запись/импорт, перенос карты и объектов, валидация, политика Atlas.
- `npm run test:browser`: Chrome, headless, 1440 × 1000. Проверены загрузка PNG, точечный маркер, стрелка, штрихованная зона, undo/redo, выделение и подпись, JSON-экспорт/импорт, сохранение после перезагрузки, смена стороны, отказ от чужого импорта, роль бойца, service worker и офлайн-перезагрузка. Ошибок JavaScript не зарегистрировано.
- `npm audit --omit=dev`: 0 уязвимостей. Полный audit сообщает 10 уязвимостей в инструментах PWA-сборки (2 low, 8 moderate); `npm audit fix` не устранил их в текущем дереве. В runtime-бандл эти инструменты не входят. Dev/preview привязаны к loopback. Перед публичным размещением обновить/перепроверить дерево сборки.
- Ручной просмотр снимка интерфейса выполнен. Полный тест на мобильном устройстве, несколько браузеров, квота хранилища, реальная TSG-авторизация и серверная изоляция не проверялись. Последние две функции ещё не реализованы.
- Atlas: прочитаны публичные страницы, клиентская формула CRS и HEAD одного тайла; фактический слой Atlas в редакторе не включался. Причины и исходные ссылки в ATLAS-RESEARCH.md.

Браузерные тесты используют собственный временный профиль, тестовые данные не добавляются в профиль пользователя.

## Локальные сетки R16

Импортированы 22 карты из указанной пользователем папки Arty Helper. Два теста импортёра проверяют signed little-endian, размер файла, физический масштаб по интервалам и направление север/юг. Браузерный сценарий с настоящей подложкой Altis проверяет масштаб 30720 м, добавление маркера, экспорт изображения внутри JSON и восстановление после перезагрузки. Исправлен прежний индикатор сохранения: после изменений он сразу показывает «Есть изменения», чтобы старый статус не принимался за сохранение новой карты.
