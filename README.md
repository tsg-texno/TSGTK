# TSG Toolkit · 0.3

Локальное PWA на React + TypeScript: восемь инструментов для подготовки, тренировки и разбора игр. Существующий Operations Planner сохранён как отдельный модуль с OpenLayers, IndexedDB и библиотекой карт. Синхронизации с игровыми серверами нет.

| Модуль | Работает в этой версии |
| --- | --- |
| Operations Planner | Карты, 16 маркеров, 7 линий и 7 зон, локальные проекты и обмен JSON |
| Preflight | Автопроверки компьютера, звук/микрофон, личный чек-лист |
| Log Doctor | Автопоиск последних RPT, группы ошибок, сравнение запусков, отчёт |
| Academy | Практика на островах и 6 моделей TFAR: квадраты, доклады, каналы и органы управления |
| Mission Explorer | Личный каталог миссий, фильтры, карточки, импорт/экспорт JSON |
| Mission Validator | Скобки, строки, комментарии, зависимости и пути в текстовых исходниках |
| Replay Insights | Ручной/импортированный журнал событий, таймлайн, фильтры и Markdown AAR |
| Personal Journal | Записи об играх, роли, заметки, выводы, поиск и экспорт |

При запуске открывается обзор. Прямая ссылка на редактор — `/#planner`; остальные инструменты выбираются слева. Документация возможностей и ограничений, контракты импорта и будущие интеграции — в [TOOLKIT.md](TOOLKIT.md). Локальное хранение не является авторизацией и не защищает записи от другого пользователя того же профиля браузера.

В Academy есть интерактивная настройка раций кнопками и регуляторами: [описание тренажёра и источников](TFAR-TRAINER.md). Разметка изображений TacticalTeam пока не сверена из-за недоступности wiki; это собственные учебные модели, не точные копии тех изображений.

## Запуск (PowerShell)

Требуется Node.js 22.12+ или 24 LTS.

```powershell
cd 'путь\к\tsg-operations-planner'
npm ci
npm run dev
```

Откройте адрес, напечатанный Vite (обычно http://127.0.0.1:5173). Если зависимости уже установлены, достаточно последней команды. На другом компьютере замените путь на папку проекта.

Для PWA и автономной работы:

```powershell
npm run build
npm run preview
```

**Для автоматического чтения RPT и проверок компьютера используйте `npm run local` вместо preview.** После первой сборки можно запускать `start-toolkit.cmd`. Подробности, права доступа и настройки путей — в [LOCAL-MODE.md](LOCAL-MODE.md). Самостоятельный запуск из обычной сессии Windows использует права вашего пользователя; управляемый процесс Codex может не иметь доступа к AppData.

Обычно http://127.0.0.1:4173. Откройте один раз с работающим сервером, дождитесь регистрации service worker, перезагрузите, затем установите через меню браузера. Работает на localhost/127.0.0.1 или HTTPS. Для обновления закройте все окна приложения и откройте снова. Не открывайте dist/index.html через file://. Dev-режим не является офлайн-PWA.

**Используйте постоянный адрес/порт и профиль браузера:** IndexedDB привязана к origin. У dev и preview разные хранилища. Чтобы перенести проект между ними, сделайте JSON-экспорт/импорт. Очистка данных сайта удаляет локальные проекты; регулярно экспортируйте резервные копии.

## Как пользоваться

1. Выберите сервер и сторону. Это 8 раздельных локальных контекстов с нейтральными именами.
2. Задайте название операции и физические размеры карты в метрах, загрузите PNG/JPEG/WebP. Замена карты очищает объекты с подтверждением. Без картинки можно рисовать на координатном поле 10 × 10 км.
3. Выберите маркер, линию или зону, цвет и подпись. Точки ставятся щелчком; ломаные и многоугольники завершаются двойным щелчком. Esc отменяет незаконченное рисование.
4. В режиме «Выбор» щёлкните объект: справа редактируются цвет/подпись, есть удаление. Вершины выделенной геометрии перетаскиваются. Колесо масштабирует, перетаскивание пустой карты перемещает вид.
5. Изменения автоматически сохраняются через 500 мс; ориентируйтесь на статус «Сохранено на устройстве». Кнопка «Сохранить» сохраняет сразу. Кнопки ↶/↷ отменяют/возвращают изменения объектов. «＋» создаёт проект, выпадающий список открывает сохранённые.
6. Экспорт — JSON с картой и объектами. Импорт валидирует данные, создаёт новый ID, не перезаписывает существующий проект; импорт чужой стороны/сервера отклоняется.

Все 16 запрошенных точечных символов присутствуют. Семь линий и семь зон сверены с полным исходным обсуждением; перечни находятся в src/domain.ts. Для старых проектов сохранены прежние названия и стили. Все классы цветов Arma 3 доступны всем объектам, совпадающие цвета объединены в один образец; дополнительно голубой TSG и произвольный цвет. Союзники по соглашению TSG — красный/розовый, противник — синий/голубой.

Роли пока демонстрационные: боец читает, штабист/КС редактируют. Это не авторизация; владелец браузера может переключить любую сторону. Настоящее разграничение будет на сервере после подключения TSG API.

## Atlas и дальнейшая архитектура

### Локальная библиотека Arty Helper

Для папок с `manifest.json` и `heightmap.r16` добавлен импортёр без дополнительных зависимостей:

```powershell
npm run maps:import -- 'C:\Users\texno\Downloads\Arty_Helper-main (1)\Arty_Helper-main\Maps-conversion\Maps'
npm run build
npm run preview
```

После обновления приложения карты появятся в списке «Локальные карты». Импортёр читает signed Int16 little-endian, учитывает направление Y и масштаб `(размер сетки − 1) × cellSize`. Максимальная сторона изображения — 2048 пикселей; исходный шаг сетки не равен разрешению изображения. Цвета высот, отмывка и линии через 25 м помогают видеть рельеф. Это визуализация высот, без дорог, зданий, растительности и названий; не полноценная топографическая карта Arma. Ненулевые originX/originY пока отклоняются.

Исходные сетки не копируются. Подложки и каталог создаются в `public/local-maps/`, исключённой из Git; после клонирования репозитория импорт выполняется на своём компьютере. Папка назначения фиксирована, содержимое исходной папки не изменяется. Исходные файлы должны быть распакованы: `.7z` импортёр не читает. Названия из папки не добавляются автоматически в белый список TSG.

Выбранная подложка сохраняется внутри проекта, попадает в JSON-экспорт и открывается офлайн. Для первого выбора другой карты нужен запущенный локальный сервер. Метаданные библиотеки входят в офлайн-кэш PWA; все изображения заранее не скачиваются. Замена карты очищает объекты с подтверждением. Проверка формата/ориентации: `node --test scripts/import-local-maps.test.mjs`.

Atlas подготовлен, но отключён: нет полученного списка островов TSG и подтверждённых прав использования. Результаты технической проверки, ссылки и поля конфигурации — в ATLAS-RESEARCH.md. Архитектура FastAPI/PostgreSQL/WebSocket, модель изоляции и ограничения — в ARCHITECTURE.md. Серверная часть в эту версию не входит.

## Проверки

```powershell
npm test
npm run build
```

Браузерные проверки: `npm run test:browser` при работающем `npm run preview`. Используют установленный Google Chrome (channel chrome). Включают все восемь модулей, сохранение/перезагрузку, перенос JSON, изоляцию сторон, офлайн-перезагрузку и мобильный обзор. Браузерные тесты запускаются в отдельном временном профиле.
